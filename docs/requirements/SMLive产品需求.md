# 1、有料模块

## 1.1 模块概述

有料模块提供专家榜单、赛事方案、推荐分析与付费解锁服务；同时串联直播、赛事和个人主页等业务模块。

## 1.2 专家排行榜

### 1.2.1 榜单与展示内容

| 榜单 | 核心指标 | 展示示例 | 计算规则 |
|---|---|---|---|
| 胜率榜 | 近7天胜率 | 85.7% | 近7天的胜场（包括赢半） / 近7天所有的  |
| 连红榜 | 当前连红数量 | 8 连红 | 直接取近期的连胜数量（过滤掉走水的） |

首页每榜展示前 9 位专家，第 10 个位置为“更多”入口。每位专家展示排名、头像、昵称及当前榜单指标，前三名可强化排名样式。

切换榜单时同步切换专家列表、排序及对应指标。点击专家进入统一用户个人主页，默认选中有料 Tab；点击“更多”进入独立专家排行榜页。

### 1.2.2 独立排行榜与上榜规则

独立排行榜支持胜率榜、连红榜切换，每榜最多展示前 30 名。列表字段与首页专家榜一致，专家点击行为也保持一致。点击上榜规则展示规则弹窗。

| 榜单 | 统计周期 | 发布数量条件 | 成绩条件 | 排序与人数 |
|---|---|---|---|---|
| 胜率榜 | 近 7 天 | 超过 5 个方案 | 命中率大于 55% | 命中率降序，前 30 名 |
| 连红榜 | 近 7 天 | 超过 2 个方案 | 近期连红数大于 2 | 连红数降序，前 30 名 |

## 1.3 焦点赛事与赛事有料

### 1.3.1 焦点赛事准入

焦点赛事支持足球和篮球，赛事必须同时满足以下条件：

1. 至少关联一个有料方案。
2. 赛事尚未开赛或正在进行。

赛事卡片展示联赛名称、开赛时间、双方队伍 Logo 与名称、有料方案数量。

### 1.3.2 赛事关联与跳转

点击焦点赛事卡片进入对应赛事详情，默认选中有料 Tab。赛事详情的有料 Tab 只展示当前赛事关联的方案，复用有料列表卡片，点击方案进入其详情。

## 1.4 有料列表

### 1.4.1 组合筛选

| 筛选维度 | 可选项 | 联动规则 |
|---|---|---|
| 体育类型 | 全部、足球、篮球 | 切换体育类型时同步调整盘口选项 |
| 盘口类型 | 全部、胜平负或胜负、让球、大小球 | 足球使用胜平负，篮球使用胜负 |
| 付款方式 | 全部、钻石、金币、免费 | 与体育及盘口条件组合生效 |

### 1.4.2 方案卡片字段与操作

| 信息分组 | 必备字段或展示内容 |
|---|---|
| 专家 | 头像、昵称、胜率、近期命中情况（如近 10 中 9）、当前连红数量 |
| 方案 | 标题、发布时间、收费方式、收费价格 |
| 赛事 | 联赛名称、开赛时间、主客队 Logo 与名称 |
| 盘口 | 推荐的盘口类型 |
| 结算状态（仅在专家主页展示，此列表不展示） | 有明确结算结果时展示结果标识 |

点击方案卡片进入有料详情。点击专家头像或昵称进入统一用户个人主页，默认选中有料 Tab。

### 1.4.3 发布时间格式

发布时间随当前时间动态计算。

| 距发布时间 | 展示格式 |
|---|---|
| 不足 1 小时 | X 分钟前 |
| 满 1 小时且不足 24 小时 | X 小时前 |
| 满 24 小时且不超过 3 天 | X 天前 |
| 超过 3 天 | 具体日期，如 2026-10-12 |

超过 3 天后停止使用相对时间。

### 1.4.4 有料列表数据排序

有料列表数据根据发布时间降序排列。

## 1.5 有料详情与购买

### 1.5.1 页面信息结构

| 区域 | 展示内容与规则 |
|---|---|
| 方案基本信息 | 标题、发布时间；结算结果（仅已结算方案显示） |
| 专家资料 | 头像、昵称、胜率、当前连红、近期战绩、关注按钮 |
| 近7天战绩 | 使用赢、赢半、走水、输半、输等标签，视觉区分不同结果 |
| 赛事信息 | 联赛、开赛时间、双方 Logo 与名称、VS/比分 |
| 盘口信息 | 根据实际玩法展示所有选项、盘口数值及发布时赔率 |
| 分析正文 | 专家发布时编辑的完整分析 |

### 1.5.2 盘口类型与呈现

| 盘口类型 | 选项展示示例 |
|---|---|
| 足球胜平负 | 主胜 1.85、平局 3.20、客胜 4.10 |
| 篮球胜负 | 主胜、客胜及各自赔率 |
| 让球 | 主队 -1.5，赔率 1.92；客队 +1.5，赔率 1.88 |
| 大小球 | 大 2.5，赔率 1.90；小 2.5，赔率 1.95 |

### 1.5.3 内容访问权限

| 用户访问状态 | 盘口展示 | 分析正文 | 解锁提示 |
|---|---|---|---|
| 未购买收费方案 | 展示盘口类型、数值及全部选项赔率；不高亮推荐方向 | 不可阅读，以毛玻璃或模糊遮罩保护 | 支付后解锁完整方案；解锁专家推荐及详细赛事分析 |
| 已购买收费方案 | 高亮专家实际推荐选项 | 展示完整正文，移除遮罩 | 不再要求购买 |
| 免费方案 | 直接展示推荐选项 | 直接展示完整正文 | 无付费遮罩或购买限制 |

**未购买的收费方案展示动态购买截止倒计时。**
**结算的方案自动解锁，即使未购买。** 

### 1.5.4 底部支付区域

尚未购买且仍在可购买时间内的收费方案，在底部固定展示方案价格、对应币种余额和“立即支付”按钮。例如：88 钻石，当前余额 1,280 钻石。

### 1.5.5 支付流程与异常处理

1. 点击“立即支付”，检查登录状态；未登录时进入现有登录流程。
2. 登录后校验方案是否仍可购买，并检查对应币种余额。
3. 余额不足时明确提示，终止支付，不扣款、不解锁。
4. 余额足够时完成模拟支付，扣除对应数量的金币或钻石。
5. 更新共享余额，将当前方案标记为已解锁，展示完整正文与推荐方向。
6. 同步更新有料首页、赛事有料列表及专家主页中的解锁状态。

### 1.5.6 购买截止规则

每个收费方案具有明确的购买截止时间；没有独立时间时，默认使用赛事开赛时间。

| 时间或权限状态 | 行为 |
|---|---|
| 截止前、尚未购买 | 显示动态倒计时，允许按支付规则购买 |
| 到达或超过截止时间 | 倒计时停止，显示“方案已截止”，禁止购买 |
| 已购买后截止 | 保留完整内容访问权限 |

## 1.6 方案结算

### 1.6.1 结算规则

#### 胜平负（足球）、胜负（篮球）

结算说明：`预测结果与实际比赛结果一致，全额赢得投注收益；否则全额输掉投注本金 `

#### 大小球

**通用公式：**

- `总进球数 = 主队进球数 + 客队进球数`
- **大球计算值**：`总进球数 - 盘口值`
- **小球计算值**：`盘口值 - 总进球数`
- 大小球盘口为 **0.25 或 0.75 结尾**时，需要拆分为两个相邻的 0.5 盘口，分别计算后再合并结算结果。

| 结算结果 | 盘口示例 | 比赛结果示例 | 公式 | 计算说明 |
|---|---|---|---|---|
| 赢 | 大 2.5 | 双方总进球数为 3 | `3 - 2.5 = 0.5 > 0` | 大球计算值大于 0，结算为赢 |
| 赢半 | 大 2.75 | 双方总进球数为 3 | 拆分为大 `2.5` 和大 `3.0`：<br>`3 - 2.5 = 0.5 > 0`，赢；<br>`3 - 3.0 = 0`，走水 | 一部分赢、一部分走水，结算为赢半 |
| 走水 | 大 2.0 | 双方总进球数为 2 | `2 - 2.0 = 0` | 大球计算值等于 0，结算为走水 |
| 输半 | 大 2.25 | 双方总进球数为 2 | 拆分为大 `2.0` 和大 `2.5`：<br>`2 - 2.0 = 0`，走水；<br>`2 - 2.5 = -0.5 < 0`，输 | 一部分走水、一部分输，结算为输半 |
| 输 | 大 2.5 | 双方总进球数为 1 | `1 - 2.5 = -1.5 < 0` | 大球计算值小于 0，结算为输 |

**开发计算规则：**

| 投注方向 | 计算条件 | 单个盘口的结算结果 |
|---|---|---|
| 大球 | `总进球数 - 盘口值 > 0` | 赢 |
| 大球 | `总进球数 - 盘口值 = 0` | 走水 |
| 大球 | `总进球数 - 盘口值 < 0` | 输 |
| 小球 | `盘口值 - 总进球数 > 0` | 赢 |
| 小球 | `盘口值 - 总进球数 = 0` | 走水 |
| 小球 | `盘口值 - 总进球数 < 0` | 输 |

大小球拆分盘口的合并规则与让球一致：

| 拆分盘口的结算组合 | 最终结算结果 |
|---|---|
| 赢 + 赢 | 赢 |
| 赢 + 走水 | 赢半 |
| 走水 + 走水 | 走水 |
| 输 + 走水 | 输半 |
| 输 + 输 | 输 |

---

#### 让球

**通用公式：**

- `净胜球数 = 所选球队得分 - 对手得分`
- `让球计算值 = 净胜球数 + 盘口值`
- 让球盘口为 **0.25 或 0.75 结尾**时，需要拆分为两个相邻的 0.5 盘口，分别计算后再合并结算结果。

| 结算结果 | 盘口示例 | 比赛结果示例 | 公式 | 计算说明 |
|---|---|---|---|---|
| 赢 | 主队 -0.5 | 主队 1:0 客队 | `1 - 0.5 = 0.5 > 0` | 让球计算值大于 0，结算为赢 |
| 赢半 | 主队 -0.75 | 主队 1:0 客队 | 拆分为 `-0.5` 和 `-1.0`：<br>`1 - 0.5 = 0.5 > 0`，赢；<br>`1 - 1.0 = 0`，走水 | 一部分赢、一部分走水，结算为赢半 |
| 走水 | 主队 -1.0 | 主队 1:0 客队 | `1 - 1.0 = 0` | 让球计算值等于 0，结算为走水 |
| 输半 | 主队 -0.25 | 主队 0:0 客队 | 拆分为 `0` 和 `-0.5`：<br>`0 + 0 = 0`，走水；<br>`0 - 0.5 = -0.5 < 0`，输 | 一部分走水、一部分输，结算为输半 |
| 输 | 主队 -0.5 | 主队 0:0 客队 | `0 - 0.5 = -0.5 < 0` | 让球计算值小于 0，结算为输 |

**开发计算规则：**

| 计算条件 | 单个盘口的结算结果 |
|---|---|
| 让球计算值 `> 0` | 赢 |
| 让球计算值 `= 0` | 走水 |
| 让球计算值 `< 0` | 输 |

对于拆分后的两个盘口，按以下规则合并：

| 拆分盘口的结算组合 | 最终结算结果 |
|---|---|
| 赢 + 赢 | 赢 |
| 赢 + 走水 | 赢半 |
| 走水 + 走水 | 走水 |
| 输 + 走水 | 输半 |
| 输 + 输 | 输 |

---


### 1.6.2 各入口展示

有料首页列表、赛事详情有料 Tab、用户主页有料 Tab 均展示已结算方案的结果。

详情在用户有权查看推荐方向时，同时表达“推荐哪个选项”与“该推荐的最终结果”。例如推荐主胜时，赢显示绿色选中并标注“赢”，输显示红色选中并标注“输”；让球及大小球遵循相同规则。

## 1.7 统一个人主页

### 1.7.1 用户身份与基础信息

普通用户、主播、有料专家及双身份用户共用统一用户身份、关注关系和个人主页。

### 1.7.2 内容 Tab 展示

| 身份 | 可展示内容 | 默认内容 |
|---|---|---|
| 仅主播 | 直播 | 直接展示直播内容 |
| 仅有料专家 | 有料 | 直接展示有料内容 |
| 主播及有料专家 | 直播、有料 | 根据入口来源选择；无来源时默认直播 |

### 1.7.3 专家有料内容

| 区域 | 需求 |
|---|---|
| 专家数据 | 近7天胜率、近 10 场命中情况、当前连红数量 |
| 近期战绩 | 展示赢、赢半、走水、输半、输，统一使用结算结果视觉样式 |
| 方案列表 | 仅展示当前专家发布的方案，包含未结算与已结算内容 |
| 卡片状态 | 复用首页样式，保留收费方式、价格、已解锁状态及结算标识 |
| 点击行为 | 进入当前方案详情 |

### 1.7.4 来源与默认 Tab

| 进入来源 | 默认选中内容 |
|---|---|
| 直播列表、直播详情主播头像、直播预告、直播回放中的主播入口 | 直播 |
| 专家排行榜、有料卡片专家头像或昵称、有料详情专家入口、其他有料业务入口 | 有料 |
| 无明确来源，用户为双身份 | 直播 |
| 无明确来源，用户仅为专家 | 有料 |
